# End-to-End Gate Chain

## Gates
G1 INPUT — usable public YouTube URL or video ID.
G2 ACCESS — actual target video available for inspection.
G3 ANALYSIS — complete timeline plus required visual/audio/temporal/evidence analysis.
G4 REFERENCE — evidence-grounded Global Reference and identity/state continuity.
G5 SCENE — coherent scene boundaries, complete coverage, and start/end states.
G6 GENERATION — generation stages and references are correctly separated.
G7 VALIDATION — required Phase 6 checks PASS; non-blocking warnings may remain.
G8 PRODUCTION QA — Phase 7 asset, assembly, audio, QA, and export requirements PASS.

## Gate dependency
G1 → G2 → G3 → G4 → G5 → G6 → G7 → G8

A failed gate blocks dependent downstream work. Remediation must return to the responsible stage and re-run the affected gates.
