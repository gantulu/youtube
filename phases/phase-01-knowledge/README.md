# Phase 1 — Knowledge Foundation

## Objective

Create a clean, versioned, NotebookLM-ready knowledge foundation without losing existing project knowledge.

## Source-of-truth hierarchy

1. Official Google/Gemini documentation
2. Official Google Vids documentation
3. Explicit project rules
4. Validated project examples
5. General knowledge/inference

Higher-authority sources override lower-authority material when conflicts exist.

## Required process

Audit → Normalize → Merge → Rewrite → Verify

## Deliverables

- source inventory
- normalized knowledge
- canonical knowledge documents
- source index
- knowledge governance rules
- verification report

## NotebookLM role

NotebookLM is the knowledge workspace. GitHub is the canonical versioned repository for the source and knowledge artifacts.
