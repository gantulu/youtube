# Generation Execution

## Execution mapping
Execute only the generation stage specified by the validated package:
- image;
- image-to-image;
- image-to-video;
- extension.

## Reference handling
Use the validated visual anchor and continuity references exactly as specified.

## Model/version handling
Use currently supported product capabilities and verify volatile model identifiers, limits, and UI behavior against current official documentation when required.

## Failure
A failed render is an asset-generation failure, not permission to invent a replacement specification. Regenerate only through an explicit retry using the validated specification or route the defect upstream.
