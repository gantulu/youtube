# Phase 7 — Production

## Objective
Define the operational production layer that executes a validated scene-generation package, verifies generated assets, assembles the final video, and records production status without bypassing upstream gates.

## Scope
Production begins only after Phase 6 validation passes. This phase covers execution, asset verification, scene assembly, audio integration, final quality checks, export, and production records.

## Pipeline
VALIDATED PACKAGE → EXECUTE → ASSET VERIFY → ASSEMBLE → AUDIO → FINAL QA → EXPORT → RECORD
