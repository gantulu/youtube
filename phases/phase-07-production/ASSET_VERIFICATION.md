# Asset Verification

Every generated asset must be checked before assembly.

## Checks
- asset exists and is readable;
- intended scene/stage matches the asset;
- visual identity and continuity are preserved;
- action/state corresponds to the validated scene;
- duration/timing is compatible with the scene plan;
- audio is present/absent as expected for the selected generation stage;
- no unintended visual or audio artifacts block use.

## Rule
An asset is not considered successful merely because a generation request completed.
