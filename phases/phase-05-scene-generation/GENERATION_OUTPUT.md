# Generation Package

The Phase 5 output is an intermediate generation package consumed by validation and downstream production.

## Required contents
- scene identifier and timing;
- source evidence linkage;
- visual anchor/reference decision;
- image or image-to-image specification;
- image-to-video specification where applicable;
- extension specification where applicable;
- continuity requirements;
- relevant audio requirements;
- unresolved constraints or uncertainties.

## Output boundary
This package is not a claim that a generated asset has successfully rendered. Rendering and asset verification belong to downstream execution/validation.
