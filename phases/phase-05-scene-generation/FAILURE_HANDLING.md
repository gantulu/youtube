# Scene Generation Failure Handling

## Missing analysis
Stop. Return to Phase 4; do not generate from incomplete evidence.

## Unsupported detail
Remove or explicitly qualify the unsupported detail; do not convert inference into observed fact.

## Continuity failure
Return to the Global Reference and relevant scene state, then rebuild the affected generation specification.

## Wrong generation stage
Reclassify the requirement as image, image-to-image, image-to-video, or extension before continuing.

## Volatile product behavior
Recheck current official documentation instead of encoding an unverified model ID, limit, or UI behavior.
