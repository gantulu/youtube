# Image-to-Image Continuity

## Purpose
Use image-to-image for later scenes when a reference is required to preserve established identity and visual continuity.

## Reference
Use the established visual anchor and/or the immediately relevant prior scene state.

## Transformation
Describe what changes between the reference state and target scene state. Preserve identity and stable attributes unless the source evidence explicitly shows a change.

## Rule
Do not regenerate a later scene from an unrelated standalone description when continuity requires a reference.
