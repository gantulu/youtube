# Visual Analysis

Capture only evidence supported by the actual video.

## Categories
- characters and persistent IDs;
- objects and persistent IDs;
- environment/location;
- action and physical state;
- composition and framing;
- camera language and movement;
- lighting and visible visual characteristics;
- relevant on-screen text.

## Identity tracking
Describe stable attributes only to the extent supported by evidence. Preserve identity across scenes and record meaningful state changes.

## Evidence discipline
Observed visual facts are primary. Inferred details must remain explicitly classified as inference; unsupported details remain unknown.
