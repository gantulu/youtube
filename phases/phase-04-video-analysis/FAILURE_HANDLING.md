# Video Analysis Failure Handling

## Invalid input
Stop and request a valid public YouTube URL or video ID.

## Video inaccessible
Stop. Do not replace missing video evidence with metadata or assumptions.

## Incomplete timeline
Return to the coverage pass.

## Sampling risk
Return to temporal verification and use an appropriate supported processing strategy.

## Ambiguous evidence
Classify as inferred or unknown and preserve the uncertainty.

## Analysis incomplete
Do not proceed to prompt planning or final scene output.
