# Video Analysis Protocol

## 1. Identify
Normalize the supplied public YouTube Shorts URL or video ID and identify the intended video.

## 2. Access
Require actual video evidence. Title, description, thumbnail, or metadata alone cannot satisfy analysis.

## 3. Coverage
Establish the complete video timeline before scene decomposition. Record timestamps using the project's canonical MM:SS representation.

## 4. Multimodal analysis
Analyze visual and audio evidence together while preserving their temporal relationship.

## 5. State tracking
Track persistent characters and objects where applicable, plus scene start state and end state.

## 6. Completion
Analysis passes only when required evidence categories are covered, temporal ambiguity has been addressed, and unsupported details are marked appropriately.
