# Gemini Skill Gates

## Gate 1 — Input
PASS only when a usable public YouTube URL or video ID is normalized.

## Gate 2 — Video evidence
PASS only when the actual video is available for analysis. Title, description, thumbnail, or metadata alone cannot satisfy this gate.

## Gate 3 — Analysis completion
PASS only after timeline, visual, audio, timestamp, and evidence-classification analysis is complete. Fast motion/rapid cuts require additional verification when sampling could miss them.

## Gate 4 — Global reference
PASS only when stable characters, objects, environment, visual style, camera/composition, lighting, and relevant audio characteristics have been captured to the extent supported by evidence.

## Gate 5 — Scene decomposition
PASS only when scene boundaries and start/end states are coherent and timeline coverage has no unexplained gaps or overlaps.

## Gate 6 — Prompt planning
PASS only when generation stages are explicitly separated: anchor/image, image-to-image where applicable, image-to-video animation, and extension/continuation.

## Gate 7 — Validation
PASS only when structural, continuity, prompt alignment, and audio/narration checks pass.

## Gate 8 — Output
Only after all required gates pass may the Skill emit the structured scene blueprint.
