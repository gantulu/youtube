# Phase 6 — Validation

## Objective
Validate the Phase 5 generation package against the verified Phase 4 evidence, Phase 2 Skill contracts, Phase 3 workflow, and locked project rules before final scene output or production execution.

## Scope
Validation is a gate, not a content-generation stage. A validator identifies defects and routes them back to the responsible stage; it does not silently rewrite source evidence or invent replacement content.

## Pipeline
INGEST → STRUCTURAL → EVIDENCE → TIMELINE → CONTINUITY → PROMPT → AUDIO → CROSS-SCENE → DECISION
