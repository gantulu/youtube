# Validation Protocol

## Preconditions
The validator receives the Phase 4 analysis package and Phase 5 generation package. Both must be available.

## Validation order
1. Structural validation.
2. Evidence alignment.
3. Timeline and boundary validation.
4. Character/object/environment continuity.
5. Prompt-stage alignment.
6. Audio/narration continuity.
7. Cross-scene consistency.
8. Final decision.

## Principle
Validate against source evidence and locked project rules. Do not validate against an invented ideal.

## Output
Produce a validation decision with explicit errors, warnings, and pass status. Do not emit a production-ready blueprint when a blocking error remains.
