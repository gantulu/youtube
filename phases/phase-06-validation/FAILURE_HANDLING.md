# Validation Failure Handling

## Structural failure
Return to Phase 5 generation package construction.

## Evidence failure
Return to Phase 4 analysis/evidence classification, unless the issue is a generation-only transformation that needs clarification.

## Timeline failure
Return to scene decomposition or generation mapping according to defect ownership.

## Continuity failure
Return to Global Reference, scene state mapping, or image-to-image planning.

## Prompt-stage failure
Correct the generation-stage mapping before execution.

## Audio failure
Return to audio analysis or audio generation requirements.

## Blocking rule
A failed validation cannot be converted to PASS by omission, suppression, or silent rewriting.
