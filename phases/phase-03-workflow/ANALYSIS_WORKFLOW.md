# Analysis Workflow

## Required passes
1. **Coverage pass** — establish the full timeline.
2. **Visual pass** — characters, objects, environment, composition, camera, lighting, actions.
3. **Audio pass** — dialogue, narration, music, SFX, timing, and relevant audio continuity.
4. **Temporal verification pass** — inspect rapid motion, quick cuts, and ambiguous transitions.
5. **Evidence pass** — classify details as observed, inferred, or unknown.

## Completion condition
Analysis is complete only when the timeline and required evidence categories have been covered and unresolved uncertainty is explicitly represented.

## No early generation
Do not create image/video prompts during the analysis passes. Prompt planning starts only after the analysis completion gate.
