# NotebookLM / Gemini Notebook

## Authority
P0 — Official Google Gemini Notebook Help.

## Source
https://support.google.com/gemininotebook/answer/16215270

## Knowledge sources
Documented sources include Google Docs, Slides, Sheets, images, audio, Markdown, text, PDF, CSV, DOCX, PPTX, web URLs, and supported public YouTube URLs with captions.

## YouTube behavior
For the documented YouTube-source workflow, only public videos with captions are supported and the imported source is the transcript text. Therefore a NotebookLM YouTube source is not a substitute for frame-level Gemini Video Understanding.

## Web and Drive behavior
Web URLs contribute page text rather than embedded media/nested pages. Drive sources can synchronize periodically with their source documents.

## Project operating rule
Use NotebookLM as the knowledge/reference workspace. Store canonical knowledge as structured Markdown/Docs. Use Gemini Video Understanding separately for actual frame-level visual analysis. GitHub remains the versioned project-of-record.
