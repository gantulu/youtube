# Canonical Terminology

- Video Understanding: multimodal analysis of video evidence.
- Static processing: sampled video processing; official default is 1 FPS.
- Agentic processing: model-dependent dynamic video inspection.
- Global Reference: stable project reference for scene consistency.
- Image-to-Image: image generation/editing conditioned on a reference image.
- Image-to-Video: video generation conditioned on image/reference and motion instructions.
- Extension: continuation generated from the end of an existing clip.
- Scene Anchor: first visual reference used to establish downstream continuity.
- Identity Lock: project validation requirement for stable identity.
- Analysis Gate: no scene output until analysis is complete.
- Validation Gate: no production until scene and continuity checks pass.
- NotebookLM: knowledge/reference workspace.
- GitHub: canonical versioned project repository.
